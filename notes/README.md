# Relay 知识库

这里是 Obsidian 笔记专区。`00-Inbox` 收集、`01-Knowledge` 沉淀知识、`02-Projects` 记录项目、`03-Resources` 收集资料、`99-Archive` 归档。

## 约定
- 笔记采用 UTF-8 Markdown；优先使用相对链接或 Obsidian 双链。
- 不要把根目录 `inbox/` 当成笔记收件箱；它属于 Codex 任务流。
- ChatGPT 修改已有笔记前应先读取最新版本，避免覆盖手机端变更。
- 私密内容不要提交到 GitHub；即使私有仓库也不是端到端加密笔记库。

详见 `../docs/OBSIDIAN_SETUP.md`。

## 文件与图片命名

仅在有**新文件首次加入** `notes/` 时，参考 [增量文件命名规则](../docs/KNOWLEDGE_FILE_NAMING.md) 检查默认名称并补充中文描述。已检查文件和历史文件不会因每次同步而重复分析；游标记录在 `config/knowledge_naming_cursor.json`。

## 今后笔记的默认排版

ChatGPT / Codex 新建或按要求整理知识笔记时，统一遵循 [知识笔记排版规范](../docs/NOTE_FORMAT.md)：

**提要 → 可跳转目录 → 详细正文 → 原始截图/附件（文末）**。

目录使用真实可跳转的 `[[#章节标题|显示名称]]` 内链，标题要一一对应；没有附件不必创建空占位。可从 [标准知识笔记模板](03-Resources/Templates/标准知识笔记模板.md) 复制开始。不要因为此规范而批量修改历史笔记。
