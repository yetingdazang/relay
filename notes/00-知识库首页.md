# 我的知识库

这里专门存放你的 Obsidian 笔记、项目知识和资料索引。手机 ChatGPT 可以把整理后的内容写入 Relay 的 `notes/`，手机与电脑 Obsidian 通过 Git 同步。

## 📥 快速入口

- [[notes/00-Inbox/README|00-Inbox · 收件箱]] — 随手记、ChatGPT 导入、待整理资料
- [[notes/01-Knowledge/README|01-Knowledge · 长期知识]] — 技术概念、方法、经验
- [[notes/02-Projects/README|02-Projects · 项目笔记]] — 需求、方案、决策、进度
- [[notes/03-Resources/README|03-Resources · 资料索引]] — PDF、图片、网页、视频链接和摘要
- [[notes/99-Archive/README|99-Archive · 历史归档]] — 暂不使用的笔记

## ✍️ 日常用法

1. 新想法、新资料先存到 `notes/00-Inbox/`。
2. 技术知识整理到 `01-Knowledge/`；项目记录放到 `02-Projects/`。
3. 原始 PDF、视频等大型附件暂时不要直接大量放进 Relay；后续可独立扩容。
4. 手机写完笔记执行 Obsidian Git 的 Commit-and-sync；要读取远程更新则先 Pull。
5. 向 ChatGPT 说“保存到 Obsidian”时，默认把提炼后的 Markdown 存入 `notes/00-Inbox/`，需要时再归类。

> 根目录的 `inbox/`、`archive/`、`AGENTS.md` 等属于 Codex 任务系统，和个人笔记不混用。

## 🧹 精简侧边栏

为此仓库提供了 `.obsidian/snippets/relay-clean-view.css`。安卓 Obsidian Pull 后进入 **设置 → 外观 → CSS 代码片段**，刷新列表并开启 `relay-clean-view`，即可在文件管理器中隐藏 Codex 技术目录及说明性 README（仅视觉隐藏；文件仍存在且正常同步）。

若要查看技术目录，关掉这个代码片段即可。详见 `docs/OBSIDIAN_ORGANIZATION.md`。
