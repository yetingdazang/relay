# Obsidian 清爽视图说明

## 设计

- **个人知识**：统一放在 `notes/`，首页 `notes/00-知识库首页.md`。
- **Codex 任务系统**：仍保留原本的根目录 `inbox/`、`archive/`、`AGENTS.md`、`config/`、`scripts/`、`templates/`，不更改原有路径。
- **显示整理**：通过纯 CSS 代码片段隐藏文件管理器中的技术文件，**不删除、不搬移、不排除 Git 同步**。

## 安卓启用步骤

1. Obsidian Git 执行 `Git: Pull` 拉取最新文件。
2. 进入「设置 → 外观 → CSS 代码片段」（英文 Appearance → CSS snippets）。
3. 如列表未更新，点击刷新按钮；启用 `relay-clean-view`。
4. 返回左侧「文件」面板，展开 `notes/`；首页为 `00-知识库首页`。
5. 到「设置 → 文件与链接 → 新建笔记的默认位置」，选择「指定的文件夹」，填写 `notes/00-Inbox`，使以后新建的笔记都存放在这里。

> 如果已打开的页面是 `未命名.base`，关闭该标签并打开 `notes/00-知识库首页.md`。CSS 只影响文件管理器，不会自动关闭已打开的标签页。

## 取消精简视图

回到「设置 → 外观 → CSS 代码片段」，关闭 `relay-clean-view` 即可恢复显示全部文件。

## 说明与限制

- CSS 会受 Obsidian 版本、主题或文件树 DOM 结构变化影响；失效时直接关闭代码片段即可，Git 文件不会损坏。
- 该代码片段并不会让 Obsidian 停止索引技术文件，也不会影响 Codex 读取它们。
- 不要用 `.gitignore` 隐藏已跟踪的技术目录；那样不能达到预期的视觉整理效果。
- 如果远程 Git 变更与本地修改冲突，先确认差异，不要强制重置。
