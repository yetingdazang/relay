# 感官消费机：人工主观体验、梦境式遗忘与神经依赖（小说设定提炼）

> [!summary] 提要
> 核心设定是一台“贩卖感受而非事件”的机器：顾客通过虚构的吸入式感官门控暂时降低对现实的感知，神经接口将预设的身体感、情绪和意识状态输入大脑；体验结束后先保留清晰的余韵，再在虚构的记忆巩固调节机制作用下如梦境般逐渐难以回忆。部分顾客不再追求影片内容，转而迷恋“离线—复位”或“逐渐遗忘”本身。机器的经济逻辑是把体验、复位与体验消失都商品化。以下明确区分真实神经科学、外推假说与纯虚构技术；不是药物、脑刺激或人体实验操作指南。

## 一、核心命题与设定边界

- **卖的不是 VR 场景，而是情绪、身体感及特殊意识状态本身。** 比如宇宙性敬畏、绝对宁静、无来由的亲密感、异样空间感，甚至人类自然经验中难以命名的复合感官。
- **完整生命周期**：现实感官离线 → 人工体验沉浸 → 现实感官复位 → 情节记忆逐渐消散；后两个阶段后来也成为依赖对象和黑市商品。
- **顾客初时能记住，随后逐渐忘却**，而不是在机器关闭时立刻失忆。体验中的短时连续感与出舱后暂时完整的回忆必须成立，才能产生“眼看记忆从自己手里流走”的感觉。
- **商业理论**：企业声称遗忘可以防止影片被记忆反复“消费”、保证每次重获新鲜感；但这只是宣传命题，不一定具有神经科学真实性。真正发生的可能是无法回忆的神经适应和条件反应持续累积。
- 科学性标记：**[实]** 有现实研究基础；**[推]** 由研究向未来技术外推；**[虚]** 小说独创，现实没有可验证的实现手段。

## 二、情绪与主观体验的组成

一段主观情绪不是单一脑区的开关，更接近以下要素持续反馈后的整体状态：

1. **感官情境**：看到、听到、触到什么，以及空间与时间如何呈现。
2. **内感受（Interoception）**：心跳、呼吸、内脏、温度、身体紧张等内部状态的感知。
3. **评价与意义**：此刻意味着什么、是否安全、是否与自我和记忆有关。
4. **神经与身体调节**：奖赏、警觉、行动准备、自主神经和内分泌变化。

同样的心跳加速可能成为恐惧、兴奋或愤怒的一部分；仅控制“情绪电极”不能保证精确重建一种感受。[实] 情绪涉及分布式神经网络与身体反馈；[推] 未来的多模态闭环系统可能比单一神经刺激更稳定。

## 三、相关脑区与神经网络

> [!important] 核心科学限制
> 脑区不是“快乐键”“愤怒键”“遗忘键”。下表描述参与的功能与可用于小说的工程想象，不是脑电极靶点或可直接执行的刺激方案。连接、个体差异与当前状态同样重要。

| 区域/网络 | 已知重要功能（概括） | 对小说装置的意义 |
| --- | --- | --- |
| **丘脑（Thalamus）与丘脑—皮层环路** | 多种感觉信息中继、注意和意识状态调节；嗅觉的初级通路有例外 | **SAG-1** 的“现实信号降权”可借用感觉门控概念；精确选择性药物门控仍是[虚] |
| **初级视觉皮层 V1 及视觉联合皮层** | 视觉特征与更高级视觉表征加工 | 人工视觉的光点/简单图案有电刺激研究；复杂真实景象写入是[推/虚] |
| **初级听觉皮层 A1 及听觉网络** | 声音特征、时间与声学信息加工 | 人工声场、方向感与“无外部声源的听感”设定参考；完整音景不可直接任意写入 |
| **初级躯体感觉皮层 S1** | 触觉和身体表面的感觉表征 | 人工触感、边界感；皮层电刺激已能诱发有限人工触觉[实] |
| **顶叶、后顶叶与多感官整合网络** | 身体位置、空间关系、多感觉协调 | 身体错位、漂浮、空间展开与感官复位中的定位恢复[推] |
| **岛叶（Insula）** | 内感受、身体状态与主观情绪体验整合 | SOMA 轨道：心脏存在感、胸腔沉重、温暖、内脏性不安；并非“情绪写入中心” |
| **杏仁核（Amygdala）** | 威胁和显著性处理、情绪学习（不只恐惧） | 恐惧、警觉和条件性情绪残留；不能简化为“愤怒电极” |
| **腹侧纹状体／伏隔核（NAcc）** | 奖赏学习、动机与趋近行为 | 渴求、强化与复购偏好；“想要”不等于“喜欢” |
| **腹侧被盖区（VTA）与相关多巴胺通路** | 奖赏预测、动机及学习相关信号 | 体验舱线索触发渴求的理论参照；不是纯粹的幸福分泌器 |
| **前扣带皮层（ACC）** | 显著性、认知控制、情绪与行动整合等 | 情绪与身体反应冲突、监测和调节[推] |
| **眶额/腹内侧前额叶（OFC/vmPFC）** | 价值评价、情绪意义、决策 | 相同刺激被体验为诱惑、威胁或满足的情境差异 |
| **背外侧前额叶及其他额叶控制网络** | 工作记忆、调节和认知控制 | 维持体验中的连续意识与自我反思；不可被简单划为“保持清醒区” |
| **海马体（Hippocampus）及内嗅皮层** | 新情节记忆的编码、关联、情境组织与检索 | **HMC-7** 的叙事基础；破坏海马功能不等于删除所有记忆 |
| **齿状回 DG、CA3、CA1（海马子区）** | 参与模式分离、联想网络和信息转换等复杂过程 | 解释类似体验为什么能被区分、为何记忆细节可能碎裂；无已知精确“遗忘药物开关” |
| **后扣带皮层、楔前叶与默认模式网络 DMN** | 自传式思维、自我相关加工等 | SELF 轨道：时间感、主体连续性、身份感的异常[推] |
| **下丘脑、脑干、自主神经网络** | 内稳态、心血管/呼吸与应激调节；下丘脑还参与内分泌系统 | 强烈情绪不能与身体生理完全分离，SPS 必须监测健康风险 |

**需要特别避免的伪科学**：

- “海马体只管长期记忆”不准确；涉及情节记忆形成与检索，并与其他区域协同。
- “杏仁核制造愤怒、伏隔核制造快乐”过度简化。
- 愤怒不等同于疼痛；“辣味之于味觉”应作为小说人物的形象类比，而不是生理学定论。
- 激素作用常有不同时间尺度，不能假设逐帧精确钳制激素和心跳就能安全生成任意情绪。

## 四、机器架构与体验编码

**NEXUS / ECHO-7** 为虚构的第七代消费终端，四大核心子系统：

| 代号 | 子系统 | 职能 | 现实性 |
| --- | --- | --- | --- |
| **SAG-1** | 吸入式感觉门控 | 降低现实感官的意识权重而尽量保留意识 | [虚] |
| **NPC-4** | 神经体验编译器 | 将多轨道感觉/身体/情绪/自我表征映射至用户接口 | [推/虚] |
| **HMC-7** | 缓释记忆巩固调节 | 使新体验的情节记忆逐渐难以长期稳定提取 | [虚] |
| **SPS** | 躯体保护系统 | 连续监测生理状态、在异常时终止体验 | [推]，监测本身[实] |

一个人工体验文件（NeuroExperience）包含四条同步轨道：

- **SENS**：视觉、听觉、触觉、空间线索。
- **SOMA**：内感受、重力/身体边界、胸腔与躯体状态。
- **AFFECT**：情绪强度、价值感、动机和奖赏体验。
- **SELF**：时间感、身份、自我位置与体验归属感。

首次使用必须进行**个人神经指纹校准**。[推/虚] 同一内容无法无差别适用所有大脑。由外部场景引发情绪比直接写入完整情绪更靠近现实技术；非侵入式 VR/声学/触觉/生理反馈可作为真实世界原型，直接多脑区写入完整主观体验仍不可行。

## 五、吸入式感官门控 SAG-1

小说中由密闭面罩提供虚构的门控介质：**外界输入被降权，而非把视觉/听觉/触觉神经直接麻痹掉；人工神经接口因此取得感知主导权**。

- 可写的感受：声音先失去方向，触觉失去身体归属，空间开始“脱锚”，但意识仍清醒。
- 技术漏洞：现实声音或触觉突然穿透门控，形成**感官泄漏**；外界工作人员一声咳嗽即可毁掉宏大幻觉。
- 科学边界：[实] 麻醉、镇静与感觉加工相关；[虚] 不存在已证实的吸入药物能安全、选择性关闭外界感觉却保留完整人工体验。
- **不定义现实药物成分、混合方法、吸入浓度或给药时序**；SAG-1 是虚构产品，不是可制造配方。

## 六、神经写入与个体化校准 NPC-4

机器不“播放视频到眼球”，而是在个人神经模型中试图重建目标的**整体主观状态**。

- 从微弱的人工空间/触觉锚点起步，调和 SENS、SOMA、AFFECT、SELF。
- 以体验者主观评分、生理信号和可用神经反馈进行**闭环校准**，而非一次发射固定数据包。
- 强调“刺激相同≠感受相同”：经历、记忆、身体状态、意义解释影响成品质量。
- 商品如《宇宙性敬畏》《无条件的温暖》《坍塌之前的寂静》并非必有可对应的现实场景。
- 人工触觉、光幻视等有初步研究[实]；任意感情与复杂意识状态的精确神经写入[虚]。

## 七、梦境式遗忘与记忆巩固干预 HMC-7

**用户确认的关键改动**：体验的感受在退出后**暂时完整保留**，之后才在虚构缓释调节效应下**逐渐无法提取**，主观质感类似醒后梦境慢慢消散；不是出舱瞬间清空记忆。

区分三个层次：

1. **情节记忆**：曾见到什么、事情怎样发生；可逐渐碎裂与难以提取。
2. **语义判断**：知道“我购买并体验过某种幸福”，但说不清内容。
3. **情绪、习惯与条件反应**：可能延续，即使情节回忆已经缺失。

理论背景：[实] 记忆包含编码、巩固、提取；长时程增强（LTP）、模式分离、系统巩固是相关概念。海马损伤研究显示，某些情绪状态能在相关事件已无法回忆时继续存在。[实] 梦境遗忘不等于“海马被关闭”；梦和记忆的生理机制复杂。[虚] 没有可精确、安全实现此选择性渐忘的已验证缓释药物。

**可写成一个连续的主观过程**：刚出舱能细述幸福 → 只能描述几个画面 → 记得“那是极大的幸福”，不记得它的质地 → 最后只剩“曾经拥有过什么”的空缺。

**核心副作用**：药效影响现实中的新记忆；有人买了十五分钟，却失去后来一整天的回忆。情节遗忘不能保证人格、身体或偏好的改变一并撤回。缓释仅保留为虚构制剂特性，不提供真实制剂路线和药代参数。

## 八、禁售情绪与身体安全 SPS

创作比喻：**“愤怒之于情绪，类似辣味之于味觉”**。它强调一种可能被追求、但伴有不适与防御反应的体验。科学限定：辣椒素涉及热/痛觉机制，愤怒本质并非疼痛；愤怒是认知、行动倾向、自主神经及内分泌反应共同参与的情绪。

强烈怒意的主观真实感可能依赖身体应激线索。如果 SPS 抑制危险身体反应，影片“味道”变淡；若不限制，则可能增加心血管与心理风险。没有“精确控制激素即可安全制造愤怒”的现成方案。

**虚构法规分级**：

| 类别 | 监管设定 | 可能的冲突 |
| --- | --- | --- |
| 宁静、温暖、轻度欣快 | 普通级 | 隐性依赖、日常奖赏对比 |
| 敬畏、失重、身体边界错觉 | 限制级 | 自我位置紊乱与感官复位困难 |
| 悲伤、孤独、恐惧 | 高危级 | 情绪残留与自主神经异常 |
| 暴怒、仇恨 | 禁售级 | 身体应激、攻击性倾向及政治禁令争议 |
| 永久离线、自我消失、刻意反复遗忘 | 禁售级 | 强迫性重入、认知损害风险 |

监管解释可以有两层：公开是健康保护，地下市场怀疑也是对“无事件依据、可批量生产的愤怒”的政治限制。

## 九、依赖、耐受与复购

**三种对象，不等同于同一种依赖**：

- **内容依赖**：追逐更强烈的新影片；日常生活可能显得苍白。
- **复位依赖**：迷恋从失去现实锚点到“重新有身体、重新听见方向”的瞬间，后来甚至不购买影片，只要离线/复位。
- **遗忘依赖**：着迷于短时间内清晰看着记忆失去形状，购买的是“失去体验的过程”。

可参考真实的“想要（wanting）≠喜欢（liking）”与奖赏学习/线索诱发渴求研究；但复位依赖、遗忘依赖本身均是**[虚] 小说医学分类**。重复体验可能在小说中出现感受耐受、线索触发、复位不再强烈、获得的愉悦降低而购买冲动仍高等表现。

**悖论**：公司阻止情节记忆固化来提高复购，却无法保证阻止程序性学习、条件反应及神经可塑性。顾客忘掉每次消费，却可能被消费逐次永久改变。

**重要的非确定性**：缺少情节回忆也可能降低信任与复购，不是科学上必然促进销售；企业可夸大甚至隐瞒这一事实。

## 十、异常感官与寂静的巨大轰鸣

**用户提供的创作素材**：濒临睡眠时，曾感到“寂静的巨大轰鸣”，近似一滴水之后发生澎湃的空间崩塌。其特殊之处是声音的巨大与寂静同时存在，难以归入普通五感。

可参考入睡期幻觉（hypnagogic hallucinations）与部分睡眠过渡异常听觉现象；某些爆炸声体验与“爆炸头综合征”有表面相似处，但**不能据描述作诊断或认定其机制相同**。

小说创造一种商品分类：**非对应性感觉（Non-correspondent Sensation）**，即没有单一物理感觉对应物的复杂复合体验。它不能通过普通视听预览：顾客“没有真正听到，却确信巨大轰鸣发生”；“没有看到坍塌，却知道整个空间在崩落”。

可保留感受描写的核心次序：

- 一滴水落下，但所谓声音似乎先于声波到达意识。
- 极大的轰鸣却拥有绝对寂静的质地。
- 崩塌的不是建筑和天幕，而是允许这些东西存在的空间自身。
- 出舱后最先丢失的不是故事顺序，而是描述这种感觉的**概念能力**。

悬念：部分顾客后来在未接入机器时偶发相同感受，究竟是神经可塑性、感官错乱，还是被机器“发现”而非创造的意识能力？

## 十一、运行流程、风险与世界观规则

### 小说中单次服务六阶段

1. 核验身份、读取个人神经指纹和健康档案。
2. SAG-1 将现实感官降权并确认仍具意识连续性。
3. NPC-4 输入四轨道体验，实时协调身体感和情绪。
4. HMC-7 使新的情节记忆处于难以稳定长期提取的虚构状态。
5. 停止人工体验，恢复真实感官优先权，即“复位”。
6. 出舱时允许短暂完整回味；随后记忆如梦消散，系统记录身体/认知异常风险。

### 企业安全条款（虚构）

- 第17条：高唤醒负性情绪、尤其暴怒的商品不得普通销售。
- 第22条：记不起影片，不等于认知功能已经恢复。
- 第31条：感官复位是安全流程，**禁止单独出售**；因此黑市出现“纯复位”服务。
- 第34条：禁止把反复制造遗忘感当成娱乐内容，出现强迫性重入须终止服务。
- 第42条：情节记忆消失不代表情绪残留、条件反应或神经适应消失。

### 技术事故

- **感官泄漏**：现实声音穿透人工世界，导致强烈失真。
- **巩固窗口溢出**：体验后的正常生活也被遗忘。
- **记忆污染**：无法回忆的体验仍改变偏好、恐惧或行为。
- **感官复位失败**：用户无法顺利恢复身体归属或现实定向。
- **情绪安全冲突**：追求“真实愤怒”导致保护系统和沉浸效果直接矛盾。
- **记录所有权争议**：顾客失去回忆，而企业数据库保留唯一可追溯的体验证据。

## 十二、情节钩子与哲学命题

- 某人要求购买复位服务，店员说已禁售四年；顾客说：“我不需要影片。我只想再回来一次。”
- 顾客忘了与逝去亲人重逢的内容，却保留了不明来源的悲伤。
- 一批人反复购买从未记住过的幸福，真实生活的趣味逐渐消失。
- 公司广告：“每次都是第一次。”内部文件却显示无法清除的情绪适应。
- 地下流通未经审查的“愤怒影片”，禁令的真实目的存在争议。
- 一款《寂静的巨大轰鸣》引起用户在现实中出现不可解释的同类感知。
- 最终争议不只是“是否能贩卖幸福”，而是**谁有权拥有、保存、删除并证明一段主观经历**。

**核心命题**：

> 消费社会不仅贩卖体验，也贩卖体验的消失。消费者以为购买了一种感受，最终却可能是在反复购买失去这种感受的过程。

延伸命题：**被遗忘的经历仍能改变一个人；记忆的产权不等于体验的产权。**
